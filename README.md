# Abuthahir & Fazila — Wedding Celebration

A cinematic, luxury Islamic wedding invitation website designed with an emerald-and-gold aesthetic, authentic Quranic reflections, GSAP smooth motion choreography, and mobile-first responsiveness.

## ✨ Features

- **Cinematic Invitation Opening**: Featuring the couple's bespoke AF gold monogram, layered architectural arches, and smooth entrance sequencing.
- **Sacred Bismillah Scene**: Authentic Arabic calligraphy (*Al-Baqarah*, *Ar-Rum*, *Al-Furqan*), delicate Mughal/Ottoman floral arabesque corners, and serene sanctuary lighting.
- **The Couple's Journey**: Interactive story section with custom portraits, groom (*Abuthahir*) and bride (*Fazila*) narratives.
- **Celebration Timeline & Itinerary**: Details for both the **Nikah** (Kumbakonam) and **Walima** (Trichy) ceremonies with interactive location mapping.
- **Hijri & Gregorian Calendar Countdown**: Ramadan / Shawwal 1448 AH interactive date indicator with live countdown to March 2027.
- **Du'a for the Couple**: Sacred prayer backdrop with floating golden starlight motes and interactive blessing petals.
- **Mobile-First Responsiveness**: Handcrafted for iOS and Android devices with safe-area notch insets, zero horizontal scrolling, and touch-optimized controls.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) (App Router, Turbopack)
- **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
- **Animations**: GSAP (GreenSock) & ScrollTrigger
- **Typography**: Playfair Display, Cinzel, Amiri, Scheherazade New, Outfit
- **Deployment**: [Vercel](https://vercel.com)

## 🚀 Getting Started

First, install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to experience the invitation.

## 📦 Production Build

```bash
npm run build
npm start
```
